--PicoScope GUI install cadence (Linux). install.sh step 1.6 installs the
  four libps*a driver packages only, not the 'picoscope' application. The
  repo and signing key it adds are the same ones the app comes from, so on
  a machine that has run install.sh the app is 'sudo apt install picoscope'
  - which also pulls drivers for every Pico product. Decide whether to make
  it an opt-in flag (PSCAN_PICO_GUI=1 / --picoscope-gui) or leave it a
  documented manual step. Not default: it is a full desktop application and
  Pico support Ubuntu/openSUSE on x86-64 only, so on Debian the package may
  not resolve at all.
--flyscan: implement 'action count' as repeating the WHOLE image, so the
  passes can be compared for drift instead of averaged blindly. That is the
  one loop worth having in a fly scan - averaging at a point is meaningless
  there, since every segment is already one pixel, and 'bin' covers signal
  per pixel. Needs a loop around RasterScan.run()'s line loop plus a pass
  index in the HDF5 line attrs so the passes can be told apart. Until then
  count > 1 is refused by flyscan/config.py rather than silently ignored.
